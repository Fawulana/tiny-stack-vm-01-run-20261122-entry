A tiny stack virtual machine for make.fun's tiny-stack-vm-01 ISA: 32-bit wrapping integers, a 256-value stack, calls, 256 words of memory, input/output, and all eleven traps with their exact exit codes. Run with `node main.ts`; it answers all 40 instances under `/input` into `/output`.
